# CodeBuddy Product Overview (International)

Last updated: 2026-03-02

## What is CodeBuddy International?

CodeBuddy International is an AI coding assistant offered by Tencent Cloud International Pte. Ltd. (Singapore). It covers three forms: CodeBuddy IDE, plugins (VS Code, JetBrains), and CodeBuddy Code CLI.

## Capabilities

- PRD generation
- Design generation
- Figma-to-code conversion
- Code completion / review
- BaaS integration (Supabase, Tencent CloudBase)
- One-click deployment (CloudStudio, EdgeOne Pages)

## Multi-Model Support

Supports various conversational large models including Hunyuan, DeepSeek, and more.

## Target Users

Individual developers and small to medium-sized teams looking for an AI coding subscription with predictable monthly pricing.

## Service Region

"This Feature is available to users globally, but primarily intended for users located in the same country/region as the selected service region for optimal performance."

## Account System

- Email or Google/GitHub OAuth
- Independent from the China mainland Tencent Cloud account system
