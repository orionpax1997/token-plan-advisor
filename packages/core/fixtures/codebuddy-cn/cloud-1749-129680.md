# 腾讯云代码助手 积分说明

## 积分发放

- 积分按月发放
- 当月有效、不累积结转
- 基础积分 + 加赠积分 = 每月实得积分

## 积分有效期

- 基础积分：自发放日起 1 个月内有效
- 加赠积分：自发放日起 1 个月内有效
- 赠送积分：自到账日起 1 个月内有效

## 积分消耗模型

Credits 消耗量由模型类型、Token 用量及任务复杂度共同决定。各模型单位消耗明细需登录个人主页查看，公开页面无换算表。

## 用量查询

- 登录 codebuddy.cn 官网
- 头像 → 个人主页 → 用量管理
- 用量查询仅在登录后可见，未提供公开 API

## 企业版积分共享

企业版团队内 Credits 共享使用；总池按订阅席位 × 2,000 Credits/月计算（200 席位 = 400,000 Credits/月池）。

## 订阅到期

"到期后降级为体验版"。连续包月 / 连续包年默认自动续费，可随时取消；月会员有效期为"新购当日 ~ 次月当日"。

## 升级与变更

- 月付 → 年付：可随时升级；未使用完的月额度可申请按比例折抵
- 套餐降级：次月起生效

## 实名认证要求

购买前必须完成腾讯云账号实名认证；未认证用户无法购买付费套餐。

## 退款政策

个人版订阅一经购买不支持退款；加量包一经购买不支持退款。
