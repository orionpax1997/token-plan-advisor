# 腾讯云代码助手 常见问题（FAQ）

> 最近更新时间：2026-07-20 19:49:30

## 数据安全

- 插件连接域名：copilot.tencent.com
- 数据传输加密
- 用户代码不作为模型训练数据（默认）

## 积分相关

**Q：积分用完了会怎样？**

A：当月积分耗尽后，对话与自动任务将无法继续，但代码补全（仅付费档）不受影响。下月积分自动到账。

**Q：积分能累积吗？**

A：不能。积分按月发放，当月有效，不累积结转。

**Q：能查看具体每个模型消耗多少积分吗？**

A：登录个人主页 → 用量管理，可查看各模型的具体消耗明细。

## 套餐升级与降级

**Q：升级套餐后旧档位积分会怎样？**

A：升级后旧档位的未使用积分不结转，按新档位的积分池重新计算。

**Q：连续包月怎么取消？**

A：个人主页 → 订阅管理 → 关闭自动续费。关闭后到期不再续费。

## 实名认证

**Q：未实名认证能试用吗？**

A：体验版（免费）可立即试用，无需实名认证。购买付费套餐前必须完成实名认证。

**Q：港澳台用户怎么认证？**

A：港澳台个人可通过微信扫码认证通道完成实名认证。

## 跨产品共享

**Q：CodeBuddy 与 WorkBuddy 积分共享吗？**

A：CodeBuddy 和 WorkBuddy 同一账号积分共享，无需分别订阅。标准版及以上同时覆盖办公智能体场景。

## 发票

**Q：能开企业发票吗？**

A：可申请增值税普通发票或专用发票，在个人主页 → 发票管理申请。

## 客服与支持

- 在线工单：cloud.tencent.com 工单系统
- 紧急支持：企业版客户专属热线

## 注册与账号

**Q：国际版和国内版账号互通吗？**

A：账号体系独立。国内站使用腾讯云账号，国际站使用 codebuddy.ai 账号。

**Q：港澳台用户可以使用国内版吗？**

A：可以，但需先完成腾讯云实名认证。

## 网络访问

**Q：海外访问国内站有问题吗？**

A：官方未发布任何关于海外访问国内站受限的声明，反之亦然。
