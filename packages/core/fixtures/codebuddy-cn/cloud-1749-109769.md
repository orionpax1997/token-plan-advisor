# 腾讯云代码助手 版本说明

> 最近更新时间：2026-08-03 15:25:00

腾讯云代码助手（Tencent Cloud CodeBuddy，简称 CodeBuddy）是腾讯云推出的 AI 编程助手，覆盖 IDE / 插件 / CLI 三种形态。

## 产品形态

- **CodeBuddy IDE**：独立桌面 IDE
- **CodeBuddy 插件**：VS Code、JetBrains、微信开发者工具、Xcode、Visual Studio、Android Studio
- **CodeBuddy Code CLI**：命令行工具

### 速率限制

- 体验版："对话和问答频率限制"（官方仅写"高频使用对话和问答时会触发限频"，无数值）
- 付费版：对话问答不限频

## 企业版

- **SaaS 企业版**：198 元/人/月（含 2,000 Credits/人/月，团队共享池，对话对话不限频）
- **专有云企业版**：316 元/人/月（100 坐席起购）
- **私有化企业版**：详情请咨询，无用量限制

## 模型清单

内置模型：Hy3（混元思考模型，限时免费）、GLM-5.2（1M 上下文）、GLM-5.1、GLM-5v-Turbo（多模态）、MiniMax-M3、MiniMax-m2.7、Kimi-K3、Kimi-K2.7-Code、Kimi-K2.6、Deepseek-V4-Flash（1M 上下文窗口）、Deepseek-V4-Pro（1M 上下文窗口）。

## 注册与认证

- 需腾讯云账号
- 完成实名认证（微信扫码 / QQ 扫码 / 人脸识别）

## 购买与续费

- 个人版：登录个人主页 > 订阅管理
- 加量包无常驻入口，需在订阅管理中或官网弹出提醒入口购买

## 速率与并发

官方页面无并发会话/设备数字段；速率仅表现为"积分消耗"+"月度池"。
