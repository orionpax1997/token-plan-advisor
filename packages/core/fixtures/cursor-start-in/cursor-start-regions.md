# Regions & Model Availability — Cursor Help Center

> 快照：https://cursor.com/help/security-and-privacy/regions（2026-09-07 抓取；页面无 Last updated 时间戳）

## Cursor Start (India)

The Cursor Start plan is only available in India. Subscribing to Cursor Start requires verifying an Indian phone number.

If you access Cursor from outside India or use a VPN, your requests may be blocked.

## Model availability by region

Some models are subject to region restrictions decided by the model provider. Certain models may not be available in your region. When this happens, those models won't appear in Cursor, but all other models continue to work.
