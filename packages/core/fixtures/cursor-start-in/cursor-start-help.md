## What is Cursor Start

Cursor Start is a regional plan for India at ₹649 per month, tax-inclusive.

Subscribing requires you to verify an Indian phone number.

## What's included

Cursor Start includes Cursor's first-party models only. Third-party models from other providers are not part of the plan.

Grok runs at a fixed medium effort on Cursor Start.

There is no on-demand usage and no third-party model pool on Cursor Start.

## Payment

Pay with UPI, as well as Indian credit and debit cards (3D Secure authentication is required).

## Availability

Cursor Start is only available in India. Availability may expand to more regions over time.
