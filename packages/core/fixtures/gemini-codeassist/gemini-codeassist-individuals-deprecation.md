# Deprecation: Gemini Code Assist for individuals

> Source: https://developers.google.com/gemini-code-assist/docs/deprecations/code-assist-individuals
>
> Last updated 2026-06-11 UTC

## Overview

Effective June 18, 2026, Gemini Code Assist for individuals (the free tier that powers the Gemini Code Assist IDE extension and the consumer Gemini CLI) will be deprecated.

## What is changing

- The free Gemini Code Assist IDE extension will no longer be available for individuals
- The consumer Gemini CLI experience will be discontinued
- Google AI Pro and Google AI Ultra subscribers will lose access to Gemini Code Assist IDE features
- Existing users will be transitioned to the Antigravity personal AI coding experience

## What is not changing

- Gemini Code Assist Standard and Enterprise editions are unaffected
- Cloud-based agent features for paying customers continue
- API access via Gemini API remains available for all developers

## Migration target

We recommend migrating to Antigravity, our new personal AI coding agent. Antigravity provides:

- IDE integration (VS Code, JetBrains)
- Agent mode with cloud task execution
- A separate quota system based on Antigravity requests

## For teams

If your team was using individual accounts for development, you should consider migrating to Gemini Code Assist Standard. Contact sales for team onboarding.

## FAQ

### Will my data be deleted?

Yes. User-specific data from the consumer experience will be deleted per the existing data retention policy. Account deletion may be requested via the standard Google account deletion process.

### Can I still use the Gemini CLI?

For personal use, we recommend Antigravity CLI. For enterprise use, the Gemini CLI is included with Gemini Code Assist Standard and Enterprise.

### What about Google AI Pro / Ultra?

The Gemini Code Assist IDE extension benefit is being removed from Google AI Pro and Ultra subscriptions as of June 18, 2026.
