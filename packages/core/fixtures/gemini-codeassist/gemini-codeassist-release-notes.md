# Gemini Code Assist Release Notes

> Source: https://cloud.google.com/gemini/docs/codeassist/release-notes

## 2026-08-20

**First-month credit discontinued for new subscribers.**

Effective August 20, 2026, the first-month usage credit previously offered to new subscribers is no longer available. New subscribers are billed the full monthly rate from the first month.

Existing subscribers (who subscribed before August 20, 2026) retain their original pricing for the duration of their subscription.

## 2026-06-18

**Gemini Code Assist for individuals deprecated.**

The free tier IDE extension and the consumer Gemini CLI have been discontinued. Users are migrated to Antigravity.

## 2026-06-08

**Gemini 3.5 Flash generally available.**

Gemini 3.5 Flash is now generally available to Gemini Code Assist users in VS Code and IntelliJ-based IDEs.

## 2026-05-15

**VS Code extension updated to v1.12.**

Improvements:

- Faster code completion
- Better context awareness
- New keyboard shortcuts
- Bug fixes for JetBrains plugin

## 2026-04-22

**Cloud-based agent mode improvements.**

- Longer-running tasks (up to 4 hours)
- Improved error recovery
- Better tool-call planning

## 2026-03-10

**IntelliJ plugin updated to v2.5.**

- Support for newer JetBrains IDE versions
- Improved code completion in Kotlin
- New chat panel features
