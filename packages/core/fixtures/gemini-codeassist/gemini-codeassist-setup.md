# Set up Gemini Code Assist Standard or Enterprise

> Source: https://developers.google.com/gemini-code-assist/docs/set-up-gemini-standard-enterprise

## Prerequisites

To purchase Gemini Code Assist Standard or Enterprise, you need:

1. A Google Cloud project
2. A Cloud Billing account attached to the project
3. The Gemini for Google Cloud API (`cloudaicompanion.googleapis.com`) enabled
4. IAM role: `consumerprocurement.orders.place`
5. Payment method on file (credit card)

For Enterprise edition, you must purchase at least 10 licenses.

## Purchase

1. Open the Google Cloud Console
2. Navigate to Admin for Gemini
3. Click "Get Gemini Code Assist"
4. Select Standard or Enterprise
5. Specify the number of licenses
6. Confirm billing

## User Setup

After purchase, end users can:

1. Install the Gemini Code Assist extension in VS Code or JetBrains IDE
2. Sign in with their Google account
3. Select the Google Cloud project associated with the subscription

## Identity Provider

Identity is managed via Google Workspace or Cloud Identity. SSO via Google is required.
