## Features

- Code completion and generation
- AI chat with code awareness
- 1M token context window
- Built on Gemini 3 family of models
- VS Code and JetBrains IDE extensions
- Cloud-based agent mode

### Enterprise Exclusive

- Code customization with your private repositories
- Apigee / Application Integration assistance
- Cloud Assist features
- VPC Service Controls support
- Customer-managed encryption keys (CMEK)

### Standard Exclusive

- Limited agent features (compared to Enterprise)
- Standard Support

## Data Handling

- Gemini doesn't use your prompts or its responses as data to train its models
- Stateless Google Cloud services: don't store prompts and responses
