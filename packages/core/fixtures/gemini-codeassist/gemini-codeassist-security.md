# Security, Privacy, and Compliance for Gemini Code Assist

> Source: https://cloud.google.com/gemini/docs/codeassist/security-privacy-compliance

## Overview

Gemini Code Assist is built on Google Cloud's enterprise-grade security infrastructure.

## IP Indemnification

Google Cloud provides intellectual property indemnification for Gemini Code Assist outputs, subject to the terms of the Cloud Data Processing Addendum.

## Compliance Certifications

- SOC 1 / SOC 2 / SOC 3 (annual audits)
- ISO/IEC 27001 (Information Security Management)
- ISO/IEC 27017 (Cloud Security)
- ISO/IEC 27018 (Cloud Privacy)
- ISO/IEC 27701 (Privacy Information Management)

## Privacy

- Gemini Code Assist does not use customer prompts or responses to train Google's foundation models
- All prompts and responses are encrypted in transit and at rest
- Data residency options available for Enterprise

## Access Controls

Identity and access management via Google Cloud IAM:

- Project-level access control
- Per-user licensing
- Audit logging via Cloud Audit Logs

## Network Security

- VPC Service Controls supported (Enterprise)
- Private Google Access available
- Identity-Aware Proxy integration

## Vulnerability Management

- Continuous security scanning
- Regular penetration testing
- Bug bounty program via Google VRP

## Incident Response

Google Cloud maintains a 24/7 incident response team. Security incidents are reported per the Cloud Data Processing Addendum.
