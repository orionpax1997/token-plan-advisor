# An Important Update: Transitioning Gemini CLI to Antigravity CLI

> Source: https://developers.googleblog.com/en/an-important-update-transitioning-gemini-cli-to-antigravity-cli/
>
> Published: May 19, 2026

## Summary

We are announcing the transition of the consumer Gemini CLI experience to Antigravity CLI, our new personal AI coding agent.

## Why Antigravity?

Antigravity provides a unified personal AI coding experience that goes beyond the Gemini CLI:

- IDE integration (VS Code, JetBrains) out of the box
- Cloud-based agent mode for longer-running tasks
- A unified quota system based on Antigravity requests
- Better integration with Google AI Pro and Ultra subscriptions

## What this means for Gemini CLI users

If you are using Gemini CLI as a personal user:

- Your existing Gemini CLI installation will continue to work until June 18, 2026
- After June 18, 2026, please install Antigravity CLI from antigravity.google
- Your API key (if you used one) will continue to work with Antigravity

## What this means for Gemini Code Assist Standard / Enterprise users

If you are a paying customer of Gemini Code Assist Standard or Enterprise:

- The Gemini CLI is included with your subscription
- Your existing Gemini Code Assist Gemini CLI installation continues to work
- No action is required

## Migration timeline

- May 19, 2026: Announcement
- June 18, 2026: Consumer Gemini CLI discontinued
- June 18, 2026: Antigravity CLI available as replacement

## Questions?

Visit the Antigravity documentation or contact Google Cloud support.
