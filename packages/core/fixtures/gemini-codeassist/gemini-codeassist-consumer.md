# Set up Gemini Code Assist (Consumer / Individual)

> Source: https://developers.google.com/gemini-code-assist/docs/set-up-gemini

## Status

Effective June 18, 2026, the consumer / individual experience of Gemini Code Assist is deprecated. New users cannot register for the free tier, and existing users have been transitioned to Antigravity.

## What was the consumer experience?

Before deprecation, the consumer experience allowed:

- Sign in with a personal Google account
- Install the Gemini Code Assist IDE extension
- Use a limited quota of requests per day
- Access the consumer Gemini CLI

## Migration to Antigravity

Antigravity provides a similar personal AI coding experience. To migrate:

1. Visit the Antigravity website
2. Sign in with your existing Google account
3. Follow the migration wizard
4. Your Antigravity account will inherit your existing preferences

## Existing Users

If you have an existing Gemini Code Assist individual account:

- IDE extension will stop working on June 18, 2026
- Your conversation history may be exported via the standard Google Takeout process
- Antigravity does not currently offer conversation history import

## For Enterprise Users

If you used Gemini Code Assist as an individual for work, please contact your IT administrator about migrating to Gemini Code Assist Standard or Enterprise.
