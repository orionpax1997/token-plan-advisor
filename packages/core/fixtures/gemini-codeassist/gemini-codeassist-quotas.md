# Gemini Code Assist Quotas

## Daily Quotas

### Maximum requests per user per day

| Tier | Agent mode + Gemini CLI | Code requests | Chat, visualization, data insight |
|------|---------------------------|----------------|-----------------------------------|
| Standard | 1500 | 6000 | 960 |
| Enterprise | 2000 | 6000 | 960 |

One prompt might result in multiple model requests.

## Rate Limits

- Requests per second: 2
- Requests are limited per user per minute and are subject to the availability of the service in times of high demand
