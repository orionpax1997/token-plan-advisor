# Gemini Code Assist Locations

> Source: https://cloud.google.com/gemini/docs/locations

## Overview

Gemini Code Assist Standard and Enterprise use Google Cloud for load-balancing, so they are able to operate globally; you can't choose which region to use.

## Service Regions

The Gemini Code Assist service runs in the following regions:

### United States

- Iowa (us-central1)
- Oregon (us-west1)
- Las Vegas (us-west4)
- N. Virginia (us-east4)

### Europe

- Belgium (europe-west1)
- Finland (europe-north1)

### Asia Pacific

- Singapore (asia-southeast1)

## GitHub Enterprise

For GitHub Enterprise integration, requests are processed in us-east1 only.

## China

There is no Gemini Code Assist region located in Mainland China.
