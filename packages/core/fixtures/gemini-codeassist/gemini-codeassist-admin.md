# Gemini Code Assist Subscription Management

> Source: https://cloud.google.com/gemini/docs/admin

## Subscription Overview

Each Cloud Billing account can have one Gemini Code Assist subscription at a time.

## Managing Licenses

To add or remove licenses:

1. Open Google Cloud Console
2. Navigate to Admin for Gemini
3. Click "Manage licenses"
4. Adjust quantity and confirm

## Cancellation

You can cancel your subscription at any time. Cancellation takes effect at the end of the current billing cycle. You will retain access until then.

## Billing

All subscriptions are billed monthly. Annual commitments are billed at a discounted rate, prorated monthly.

## Identity

Subscription is tied to the Google Cloud project and Cloud Billing account. User access is managed via IAM.

## Reporting

Usage reports are available via Admin for Gemini → Reports. Aggregate and per-user views are available.

## Enterprise Requirements

Enterprise edition requires a minimum of 10 licenses. Adding more licenses is allowed at any time. Reducing below 10 requires Enterprise Sales contact.
