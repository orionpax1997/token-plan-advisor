# On-Demand Usage

> Source: https://docs.trae.ai/ide/on-demand-usage

## What is On-Demand Usage?

On-Demand Usage is an additional usage capacity that allows you to continue using TRAE after your Basic Usage is exhausted.

## When is On-Demand Usage triggered?

On-Demand Usage can be enabled by Lite and above plans. After Basic Usage is exhausted, usage automatically draws from On-Demand.

## How is On-Demand Usage billed?

Each time the accumulated amount reaches $3, a payment will be triggered. Charges are billed at the model's API rates with no markup.

## Can I set a monthly cap?

Yes. You can set a monthly On-Demand Usage cap in TRAE Console → Plan & Billings → Usage Limits.

## How do I disable On-Demand Usage?

1. Go to TRAE Console
2. Click Plan & Billings
3. Toggle off On-Demand Usage

## Where can I see On-Demand Usage history?

Visit the Usage page on TRAE.ai, where you can find detailed records of each transaction in Usage Events.
