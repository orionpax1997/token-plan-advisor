# Anthropic API（Claude Platform / Messages API）官方信息来源调研

- **采集日期**：2026-09-07
- **调研范围**：Anthropic Claude API 当前定价、当前模型族、Rate limit / usage tier 体系、Prompt caching、Batch API、Tool use（含 server tools）、Structured outputs、Citations、Fast mode、Data residency、ZDR / HIPAA / 数据训练/保留政策、China Availability。Claude 订阅、Claude Code、Claude.ai chat 与 `.scratch/.../research/07-anthropic-claude-code.md` 的覆盖范围互不重叠，本文不重复订阅/Claude Code 字段。
- **方法**：仅使用一手官方来源（platform.claude.com/docs/、docs.anthropic.com、anthropic.com 官方公告/博客、support.claude.com 帮助中心、privacy.claude.com、trust.anthropic.com）；通过 exa 搜索定位官方页面并抓取关键段落，必要页面再用 curl 直接抓取核对。第三方汇总站、媒体转载、博客解读均不作为事实依据；Exa 免费档本日配额耗尽时仅作为定位辅助，最终事实以官方页面内容为准。无法确认的字段如实标注。

## 结论摘要

1. **Anthropic 当前对外出售的"Plan Type = api-usage"** 形态是 **Claude Platform API（first-party Messages API）**，按 token 用量计费，**没有"月度订阅 / 季度 / 年付"的 plan 概念**——只有"usage tier + spend cap"。Claude Pro/Max/Team/Enterprise 订阅与 Claude Code 已在 07-anthropic-claude-code.md 覆盖，不属本调研。Claude.ai chat 个人层虽并列在同一控制台账户体系内，但订阅与 API credit 是两条独立计费通道（"Your Claude.ai subscription … and API credit are independent charges on the same card"，见 [Console 开发者指南（第三方页面，仅引用其对官方事实的归纳）](https://tygartmedia.com/anthropic-console-developer-guide-2026/)，对应官方原文为 Console Help Center 与 [How do I pay for my Claude API usage](https://support.claude.com/en/articles/8977456-how-do-i-pay-for-my-claude-api-usage)）。
2. **当前有效定价矩阵（USD / 1M tokens，first-party API 标准 Global tier）**：Claude Fable 5.x/Mythos 5.x **$10 输入 / $50 输出**；Claude Opus 5 / 4.8 / 4.7 / 4.6 / 4.5 **$5 / $25**；Claude Sonnet 5 **$2 / $10**（原拟 2026-09-01 调至 $3/$15 已取消，详见 §4）；Claude Sonnet 4.6 / 4.5 **$3 / $15**；Claude Haiku 4.5 **$1 / $5**。所有模型 5-min cache write ×1.25、1-h cache write ×2.0、cache read ×0.1（Claude Fable 5.1 / Mythos 5.1 例外为 ×0.025）。Batch API 一律 50% off。详见 [Pricing 文档](https://platform.claude.com/docs/en/about-claude/pricing)。
3. **Rate limit / usage tier 是本 Plan Type 的"额度"字段**：4 个自动 tier（Evaluation / Start / Build / Scale）+ Custom。月度 spend cap：Start $500、Build $1,000、Scale $200,000。RPM/ITPM/OTPM 按 tier 与模型族给出明确表格。详见 [Rate limits 文档](https://platform.claude.com/docs/en/api/rate-limits)。
4. **Prompt caching、Batch API、Tool use、Fast mode、Citations、Structured outputs 全部为同一 API 形态下的功能维度**，不另立 Plan：cache 1.25×/2× 写入 + 0.1× 读取；Batch 50% 折扣；Web search $10 / 1K searches；Code execution 1,550 free hours/月，超出 $0.05 USD per hour per container；Fast mode（research preview）Opus 5/4.8 标准价 ×2。详见 §3 与 [Pricing 文档](https://platform.claude.com/docs/en/about-claude/pricing)。
5. **中国 Availability 五个维度均能从官方一手来源直接确认**：① 服务地区清单明确不含中国大陆（[Supported Countries](https://www.anthropic.com/supported-countries) 列出 ~160 个国家/地区，含台湾、不含中国大陆、香港、澳门）；② 官方 2025-09-04 公告将"被不支持地区司法管辖的公司（含 >50% 间接持股结构）"列为禁用对象，明确点名 China（[Updating restrictions of sales to unsupported regions](https://www.anthropic.com/news/updating-restrictions-of-sales-to-unsupported-regions)）；③ Help Center 文档与 [API overview](https://platform.claude.com/docs/en/api/overview) 均提示"check the supported regions page"。**未确认**的细节：大陆终端用户实际能否注册个人 Console 账户；支付链路在大陆的官方支持范围（实测社区报告多用 Stripe 失败、需走 AWS Bedrock / GCP Vertex / Azure Foundry 三条 partner-operated 通道之一）。
6. **历史定价频繁调整**：本页覆盖的核心变动包括 Claude Sonnet 5 在 2026-09-01 之前原计划上调到 $3/$15、随后官方宣布该涨价**不会生效**；Claude Opus 4.x 自 4.5 起统一调至 $5/$25（前期 Opus 4 / 4.1 为 $15/$75）；Batch 自 2024 以来长期保持 50% off；缓存折扣倍率不变。详细历史见 §4。

## 3. 价格/额度的原始表达方式与归一化歧义

### 3.1 官方原始表述（照录）

- **核心单价**："$10 / MTok"、"$5 / MTok"、"$3 / MTok"、"$2 / MTok"、"$1 / MTok" 等等——MTok = Million tokens；列名"Base Input Tokens"、"5m Cache Writes"、"1h Cache Writes"、"Cache Hits & Refreshes"、"Output Tokens"。
- **Cache 倍率**："5-minute cache write | 1.25x base input price | Cache valid for 5 minutes"、"1-hour cache write | 2x base input price | Cache valid for 1 hour"、"Cache read (hit) | 0.1x base input price (0.025x on Claude Fable 5.1 and Claude Mythos 5.1)"。
- **Batch**："All usage is charged at 50% of the standard API prices."（[Batch processing 文档](https://platform.claude.com/docs/en/build-with-claude/batch-processing)）。
- **Fast mode**："Fast mode pricing applies across the full context window, including requests over 200k input tokens. Fast mode is available on the Claude API (first-party) only; it is not available on Claude Platform on AWS or partner-operated cloud platforms."
- **US-only inference**："For Claude 4.6 and later models, specifying US-only inference through the `inference_geo` parameter incurs a 1.1x multiplier on all token pricing categories, including input tokens, output tokens, cache writes, and cache reads. Global routing (the default) uses standard pricing."
- **Spend cap**："| Usage tier | Monthly spend cap | Start | $500 USD | Build | $1,000 USD | Scale | $200,000 USD |"；"Organizations on the Custom tier have no monthly spend cap; limits are arranged with their account team."
- **Rate limit**："The rate limits for the Messages API are measured in requests per minute (RPM), input tokens per minute (ITPM), and output tokens per minute (OTPM) for each model class."
- **Tool use 计费**："Tool use requests are priced based on: The total number of input tokens sent to the model (including in the `tools` parameter); The number of output tokens generated; For server-side tools, additional usage-based pricing (e.g., web search charges per search performed)."；"Client-side tools are priced the same as any other Claude API request, while server-side tools may incur additional charges based on their specific usage."
- **Tool use 系统 token 增量**：每个模型 + tool_choice 组合增加一定 tokens 到 input（如 Opus 4.8 auto/none = 290 tokens；any/tool = 410 tokens；Opus 4.7 auto/none = 675 / any 804；Haiku 4.5 auto/none = 496 / any 588）。
- **Web search**："$10 / 1K searches"（[Pricing 文档](https://platform.claude.com/docs/en/about-claude/pricing)）。
- **Code execution**："Each organization receives 1,550 free hours of usage per month. Additional usage beyond 1,550 hours is billed at $0.05 USD per hour, per container."（[Code execution tool 文档](https://platform.claude.com/docs/en/agents-and-tools/tool-use/code-execution-tool)）；"Code execution is free when used with web search or web fetch."——即与 web search/web fetch 同请求时不再单独收容器费。
- **Citations**："Citations uses our standard token-based pricing model. While it may use additional input tokens to process documents, users will not pay for output tokens that return the quoted text itself."（[Citations 介绍博客](https://claude.com/blog/introducing-citations-api)）；官方文档补充："Enabling citations incurs a slight increase in input tokens because of system prompt additions and document chunking."

### 3.2 跨 Vendor 归一化歧义清单

1. **"额度"双轨**：Anthropic 没有"月消息数"或"月 token 包"，只有"spend cap（美元）"+"每分钟 rate limit（ITPM/OTPM）"。跨 Vendor（Cursor 的"$20 API 价 third-party 模型池"、GitHub Copilot 的"高级请求数"、Codex 的"消息额度"）对比时，**Anthropic 的"用量池"应建模为 $amount-of-credit（按 token 实时计费，无月度配额概念）**，而非消息数；超出 spend cap 即停服，无额外按消息计费。
2. **"MTok" vs Vendor 普遍习惯**：Anthropic 用 "MTok = 1,000,000 tokens" 作为基本单位，与 OpenAI、Google、Cursor 一致；但 Sonnet 4.x、4.5、4.6 / Opus 5 / 4.x 之间同样 $X/MTok 输入下，cache write/read 倍率差异（1.25×/2×/0.1×）会让"等效 input 单价"在三种使用模式下相差 2-10 倍。归一化时**应同时输出裸 input 价 + 三种典型 cache 使用场景的等效 input 价**。
3. **Batch 折扣的"双层叠加"**：cache read 在 batch 内仍按 0.1×（=batch input 价的 0.1×）；官方明示"hits are best-effort, observed hit rates ranging from 30% to 98%"——归一化时不能用"0.5×0.1=0.05×"做单点估值，必须把 hit-rate 当独立变量。
4. **Fast mode 与服务层级混淆风险**：Fast mode ×2 是 *模型特性*（仅 Opus 5/4.8），与 Service tier 的 Priority Tier **不同**；Priority Tier 是 *按 token/min 承诺费* 的容量预留（"Priority Tier capacity commitments are no longer available for purchase"），且 burndown 系数与价格倍率完全独立。
5. **US-only inference 不是"免费美国境内"**：选 `inference_geo: "us"` 是付 1.1× 换数据驻留承诺，不是 0.9× 折扣；只对 Claude 4.6+ 模型生效；早期模型直接 400 error。
6. **Covered Models 30-day 强制保留**：Fable 5、Mythos 5 是 Covered Models，**该模型对 ZDR 组织返回 400**——这与"商业 API 默认不训练 + 30 天删"的"宽松默认"形成显著差异，归一化"数据保留"字段时必须把 Covered Models 单独建模。
7. **Fast mode 不开放给所有模型**：仅 Opus 5 / Opus 4.8（"Fast mode is not available on Opus 4.7 … or Claude Opus 4.6"），且仅 first-party API 可用——Bedrock / Vertex / Foundry 三条 partner 通道**不支持** fast mode；跨 Vendor 比较 fast 模式时需在 schema 中标注 platform 字段。
8. **Tool use 的 token 增量易被低估**：`tools` 参数内每个 tool schema、tool_choice 切换（`auto` vs `any`）、interleaved-thinking 启用都会增加输入 token；Opus 4.7 仅 `tool_choice: auto/none` 即 +675 tokens（[Tool use overview 表](https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview)）。归一化时应提示"输入 token = 实际 message tokens + tool/system 增量"。
9. **Rate limit 维度 = 3 个 metric × 5 个 tier**：RPM / ITPM / OTPM 同时独立 429；不能简化为单一"RPM"。Help Center 原文："If you exceed any of these rate limits, you will get a 429 error describing which rate limit was exceeded"。
10. **Service tier ≠ Plan**：Standard / Priority / Batch 是**每请求可选**的 service tier 维度（`service_tier: "auto" | "standard_only" | "batch"`），与 organization 的 usage tier（Start/Build/Scale/Custom）正交；同一 organization 可同时在 Build tier 且单条请求走 Priority Tier。归一化时这两个维度必须独立建模。
11. **Web search 计费单位是"搜索次数"非 token**：$10 / 1K searches 不管搜索结果多少 token；与"按 input token 计"的同页面表格不能直接相加。Code execution 又是按"container-hour"计（$0.05/h, 5 min minimum），三种 server tool 计价单位各不相同。
12. **Invoice 最小金额**：月结客户 < $0.50 的金额滚到下月，**prepaid credit 客户不受此限**——同页面区分两种计费通道的最小阈值；归一化"计费周期/最小扣款"字段时须把 channel 字段加上。

## 4. 来源冲突、更新频率与历史变更方式

### 4.1 来源冲突（已识别的 1 处，自洽解决）

- **Pricing 文档"Claude Sonnet 5 涨价时间表"自相矛盾**：同一页面有两段关于 2026-09-01 涨价的文字——
  - 第一段（早期版本仍可见）："Introductory pricing of $2/$10 per million input/output tokens is in effect through August 31, 2026, after which the standard pricing of $3/$15 per million input/output tokens will take effect."
  - 第二段（较新注释）："The $2/$10 per million input/output token pricing for Claude Sonnet 5, announced at launch as introductory pricing through August 31, 2026, is now the standard price. The previously scheduled increase to $3/$15 per million input/output tokens on September 1, 2026 will not occur."
  - **本次采集日 2026-09-07，已过 2026-09-01，采纳第二段为现行值**：Sonnet 5 = $2 / $10；Sonnet 4.6 / 4.5 / 4 = $3 / $15。表格本身已按 $2/$10 列出（已不含"through August 31"分列），"starting September 1, 2026"行**已在采集版本中保留作历史注脚但当前不生效**。
- **价格 PDF 时间序列**（按发布日命名）：2026-05-12 / 2026-05-27 / 2026-06-29 三个版本；模型相同（Opus 4.5/4.6/4.7、Sonnet 4.5/4.6、Haiku 4.5）单价**未变**，PDF 的更新主要用于补全 partner 平台（Bedrock / Vertex / Foundry）的 regional pricing 矩阵。说明这是"价格表归档快照"而非"价格变更通告"。

### 4.2 更新频率

- **Pricing 主表**：约 1–3 个月一次重大变更（模型新增/退役、官方调价）。从 2025-08 至 2026-06 至少 3 次主表重排（新增 Sonnet 4.5、Sonnet 5、Opus 4.8、Opus 5 等模型均伴随表格刷新）。
- **Help Center 文章**：约月度更新；页脚时间戳可见。
- **Beta features**：约周-月节奏（`anthropic-beta` header 的日期后缀即发布日）。
- **Models overview 表**：随模型 GA/Preview 状态调整；"Retirement"列显式给出"Not sooner than …"承诺日期。
- **官方博客**：模型发布配套博客 + 重大政策公告（如 2025-09-04 regional restriction 强化）。

### 4.3 历史变更方式（已可考的官方记录）

- **2025-09-04**：发布 [Updating restrictions of sales to unsupported regions](https://www.anthropic.com/news/updating-restrictions-of-sales-to-unsupported-regions)，将"被不支持地区（如中国）司法管辖的公司"纳入禁用范围，明确"more than 50% owned, directly or indirectly, by companies headquartered in unsupported regions"亦在禁用之列。
- **2025-06-23**：发布 [Introducing Citations on the Anthropic API](https://claude.com/blog/introducing-citations-api)，Citations 功能 GA；2025-06-30 更新称 Bedrock 也已支持。
- **2026-XX**（定价页正文确认）：Claude Sonnet 5 原本计划 2026-09-01 调至 $3/$15，**官方宣布该调价不生效**，$2/$10 永久化为标准价。
- **历史 Opus 4 → Opus 4.5 价格下调**：Opus 4 / 4.1 标准价 $15/$75（deprecated），Opus 4.5 起统一调至 $5/$25；老模型仅在 Bedrock / Vertex 继续可用。
- **Long context pricing 取消**：Pricing 文档明确"Claude 4.6 and later models and Claude Mythos Preview include the full 1M token context window at standard pricing"——历史 Opus 4 / 4.1 的 200K 以上分段加价不再延续到 4.6+。
- **Priority Tier 停止新增销售**：Service tiers 文档顶部："Priority Tier capacity commitments are no longer available for purchase. Organizations with an existing commitment can continue to use Priority Tier through their contract end date."
- **ZDR 政策**：原本覆盖更广；2026 起 Fable 5 / Mythos 5（Covered Models）明确**不支持 ZDR**，强制 30 天保留。

### 4.4 页面是否显示更新时间

- **Pricing 文档**：表格有"starting Sept 1, 2026"等时间分列；正文有"Last updated" 风格的注释段落。**版本化 PDF 提供官方时间轴归档**（5-12 / 5-27 / 6-29 三版可下载）。
- **Help Center 文章**：页脚日期（如 Rate limits 概述 2026-06-26、How do I pay 2026-08-19）。
- **API 文档（tool use、batch processing、citations 等）**：通常**无 Last updated 标记**；价格/弃用等重大变更通过 Pricing 文档与 Models overview 表传播。
- **Models overview 表**：明确带 "Retirement" 列、"Reliable knowledge cutoff"、"Training data cutoff"，是结构性时间字段。
- **Privacy Center 文章**：按发布日期标注（"Published 2026-03-16T21:18:31.000Z" 等）。

### 4.5 无法确认当前有效值的字段

- **Exact tier 升档规则**：Help Center 原文 "Organizations are placed on a tier automatically based on usage history and account standing and can move to a higher tier over time as they use the API"，但**未给出具体的"消费 $X → 自动升 Start 到 Build"门槛数值**。
- **Identity verification 适用国家细项**：2025 年引入，但官方页面（截至采集日）只列 Supported Countries 名单 + ID 验证机制存在；**未逐国列 ID 验证强制 / 自愿 / 不适用矩阵**。
- **中国大陆实际注册可行性**：官方 supported-countries 名单不含中国大陆，公告明确 ownership 限制；但**官方未明确"中国大陆终端用户在第三方国家 VPN/出差场景下使用 Console 是否允许"**——社区报告显示账号可能被封，但官方未发布针对个人使用者的统一规则文本。
- **中国大陆支付方式**：官方未公布"哪些国家/币种可通过 Stripe 完成自助 credit 购买"清单；社区报告（意大利、匈牙利、比利时等欧洲国家 Stripe 拒付、需换浏览器绕开 Link autofill）说明**官方对"哪些国家可成功购买"无明确边界**。
- **Fast mode 是否会被纳入非 Opus 5/4.8 模型**：官方"research preview"措辞暗示扩展可能，但**未公布后续模型覆盖计划**。
- **Future Tier 名称与门槛**：当前公开为 Evaluation / Start / Build / Scale / Custom 5 档；**未来是否新增 tier 未公布**。

## 6. 对 Data Provider / Recommendation Policy 的建议（供后续 ticket 引用）

- **最小来源契约**：`platform.claude.com/docs/en/about-claude/pricing`（价格矩阵 + cache + batch + fast + US-only 完整表）+ `platform.claude.com/docs/en/api/rate-limits`（tier 表 + 月度 spend cap + Fast/Priority tier 备注）+ `www.anthropic.com/supported-countries`（地区清单）+ `support.claude.com/en/articles/8977456`（prepaid credit + Stripe）+ `platform.claude.com/docs/en/manage-claude/api-and-data-retention`（训练/保留/ZDR/HIPAA）——五页可覆盖核心字段，全部静态可抓。
- **核心字段（缺失应阻止强排名）**：价格（按模型 × token 类型展开）、币种、usage tier、service tier、月度 spend cap、RPM/ITPM/OTPM 三轴、cache 倍率、Batch 折扣、Fast mode 倍率、US-only inference 倍率、数据训练政策、默认保留天数、ZDR 可用性（注意 Covered Models 例外）、地区可用性。
- **失败分类建议**：`OK`（静态 pricing/docs/help 全文）/ `RENDER_DEPENDENT`（Models overview 等含 tab 切换的页面；替代方案 = 关键段直接抓取）/ `LOGIN_REQUIRED`（Console Dashboard、Rate Limits API 实际调用、Admin API）/ `TIME_DEPENDENT`（Pricing 文档含"starting Sept 1, 2026"等时间分列；Provider 必须记录采集日期并验证该时间点是否已过）。
- **跨 Vendor 归一化提示**：将"Plan Type = api-usage"的 Anthropic 用量池建模为 **prepaid credit $amount × usage tier × tier-capped spend**，而不是消息数或 RPM；tool/server tool 增量应作为独立字段（web search per-1K、code execution per-container-hour、citations 是 token 但 cited_text 不计 output）。
- **Covered Models 必填标注**：Fable 5、Mythos 5 因 30 天强制保留 + 不支持 ZDR，归一化"数据保留 / 训练"字段时须把"is_covered_model"作为独立字段。
