# Anthropic Claude 订阅 + Claude Code 官方信息来源调研

- **采集日期**：2026-09-07
- **调研范围**：Anthropic 当前有效订阅层级（Free / Pro / Max 5x / Max 20x / Team Standard & Premium / Enterprise self-serve & sales-assisted），以及 Claude Code 作为 Anthropic 官方产品（CLI、Desktop、VS Code / JetBrains / Open VSX 扩展、GitHub Actions）与 Anthropic API 的区分。Anthropic API 单独定价由另一个 agent 调研，本文不重复覆盖 platform.claude.com/en/docs/pricing 的 token 价目表。
- **方法**：仅使用一手官方来源（claude.com 营销页、support.claude.com 帮助中心、code.claude.com 文档、docs.claude.com / platform.claude.com、anthropic.com 公告、privacy.claude.com、github.com/anthropics、JetBrains/VS Code 插件市场条目、Anthropic 旗下 release-notes 周报）；第三方站点（continuumcode、tomsguide、Reuters 等）**不作为事实依据**，仅用于指向官方原文位置。无法确认字段如实标注。

## 结论摘要

1. **订阅层级的官方清单**（消费者层：Free、Pro、Max 5x、Max 20x；组织层：Team Standard、Team Premium、Enterprise self-serve、Enterprise sales-assisted）——名称、价格档位、可访问产品（Claude Code / Cowork / Claude Design / Claude for Microsoft 365 等）均见 [claude.com/pricing](https://claude.com/pricing)。Free **不含** Claude Code；Pro 月付 $20、年付 $17/月（$200 一次性）；Max 5x $100/月、Max 20x $200/月，仅月付。Team 2–150 人，每成员月付 Standard $25 / Premium $150（Premium 含 Claude Code 与更高用量），年付相应降为 $20 / $100；Enterprise 唯一官方公开价是"每坐席 $20/月加 API 用量"（按 usage 计费，无套餐用量上限）。
2. **Claude Code 用量官方表述是"消息/小时 + 周窗口"两层制**，无 token 数值公开：Pro 用户"约 45 条消息 / 5 小时"或"10–40 个 Claude Code prompt / 5 小时"，Sonnet 4 周限额约 40–80 小时；Max 5x 对应 225 消息或 50–200 prompt、Sonnet 140–280 小时、Opus 15–35 小时；Max 20x 对应 900 消息或 200–800 prompt、Sonnet 240–480 小时、Opus 24–40 小时；周窗口与 5 小时滚动窗口同池跨模型共享，Opus 有独立池，Fable 5 占周池最多 50%。**原始官方原文**保留在 help center `articles/11145838`、`articles/14552983`、`articles/9797557`、`articles/11049741`。
3. **Claude Code 与 Anthropic API 是两套独立计费**：订阅内 Claude Code 用量取自订阅套餐池；API 用户按 token 计费，Claude Code 在 v2.1.198 起可用 OAuth token（`CLAUDE_CODE_OAUTH_TOKEN`，由 `claude setup-token` 生成），亦可用 `ANTHROPIC_API_KEY` 或 Bedrock / Vertex / Foundry 凭据。代码文档原话："Claude Code charges by API token consumption. For subscription plan pricing (Pro, Max, Team, Enterprise), see claude.com/pricing"。归一化时不可混用"消息数"与"token 数"。
4. **历史变更**：Claude Code 2025-02-24 随 Claude 3.7 Sonnet 以 research preview 形态发布（[news/claude-3-7-sonnet](https://www.anthropic.com/news/claude-3-7-sonnet)）；2025-05-22 随 Claude 4 GA（[news/claude-4](https://www.anthropic.com/news/claude-4)），增加 VS Code / JetBrains 扩展与 GitHub Actions 后台；2025-06-04 开放给 Pro 计划（[Using Claude Code with your Pro or Max plan](https://support.anthropic.com/en/articles/11145838-using-claude-code-with-your-pro-or-max-plan)）；Max 2025-04-09 首发为单一 $200 档，2025 年内陆续加挂 $100 档并扩容 5 小时窗口（2026-05-06 翻倍）。免费层从未包含 Claude Code；Team Standard 2025 年内升级加入 Claude Code（[release notes](https://support.claude.com/en/articles/12138966-release-notes)）。
5. **中国 Availability**：anthropic.com/supported-countries 列出的 Claude.ai 可用地区清单**不含中国大陆**（[supported-countries](https://www.anthropic.com/supported-countries)）；[news/updating-restrictions-of-sales-to-unsupported-regions](https://www.anthropic.com/news/updating-restrictions-of-sales-to-unsupported-regions)（2025-09-04）明确点名 China 为"unsupported region"，并把 50%+ 控股结构属中国的企业纳入限制——这是 Anthropic **官方明确声明**。CLI 在中国大陆触发 400 "Access to Anthropic models is not allowed from unsupported countries" 错误（[github.com/anthropics/claude-code issue #2656](https://github.com/anthropics/claude-code/issues/2656)）属产品行为一致的直接证据。

### 3.2 归一化歧义清单

1. **三层用量制不可线性换算**：5 小时滚动窗口（burst）+ 周窗口（volume）+ Opus 池（model-scoped）；5 小时窗与周窗跨模型共享，Opus 池独立——切换模型不会"恢复"前两者，只会换到 Opus 池内剩余空间。Max 的 5x/20x 倍数是**按 Pro 计的相对量**，无 token 绝对值。归一化需建模为三维桶而非单一数字。
2. **"消息/5 小时"与"prompt/5 小时"是两套单位**：claude.ai chat 的消息 vs Claude Code 的 prompt，两者在同一 5 小时池内合计；官方原话明确"shared across Claude and Claude Code"。
3. **周窗口单位是"小时数"而非"消息数"**：Pro 40–80 hours of Sonnet 4；这是 Sonnet 模型的**使用时长**而非 token 数，与 Cursor 的"Other Models $20 / 月"或腾讯 CodeBuddy 的"积分"无直接可比。
4. **Max 自动降档机制**：Max 5x 在 20% 时 Opus→Sonnet、Max 20x 在 50% 时降级——这是 Pro/Max 不公开"何时降级"的官方机制描述，"power users"实际能用的 Opus 容量小于数字直觉。
5. **Pro 与 Team Standard 计 Usage credits**：当用量超出套餐池时启用 usage credits，超出部分按 API 价计费（[Pro plan](https://support.claude.com/en/articles/8325606-what-is-the-pro-plan)、[usage best practices](https://support.claude.com/en/articles/9797557-usage-limit-best-practices)）；归一化时不能把 Pro 视为纯"包月不限量"。
6. **Enterprise 套餐 = $20/seat + 全量 API**：该模型与 Pro/Max 的"包月含用量池"完全不同——Enterprise 的"per-seat fee"只覆盖访问权限，所有 token 用量按标准 API 价另收（"billed separately at standard API rates"）；跨 Vendor 比较时不应直接比 $20。
7. **API key vs OAuth token**：Claude Code v2.1.198 起 OAuth 登录支持 Pro/Max/Team/Enterprise；GitHub Actions 既可用 `ANTHROPIC_API_KEY`（API 用量），也可用 `CLAUDE_CODE_OAUTH_TOKEN`（订阅池用量）——同一 CLI/Action 在不同认证下进入**不同的计费路径**，需在 schema 中单独建模。
8. **免费层从未含 Claude Code**："The free Claude.ai plan does not include Claude Code access"（[installation](https://code.claude.com/docs/en/installation)）。归一化时不应给 Free 层标"含 Claude Code"。
9. **桌面应用 vs Web 入口**：价格 Compare 表按"Free/Pro/Max/Team/Enterprise"维度对比，含"Chat on web, iOS, Android and Desktop"——同一定价层在多 surface 间共享池；"Mobile pricing may vary depending on your app platform"（[Max plan](https://support.claude.com/en/articles/11049741-what-is-the-max-plan)），iOS App Store / Google Play 价格与官网可能不一致。
10. **Team Standard 是否含 Claude Code**：当前 help center 与 release notes 已声明"Claude Code access added to Team plan Standard seats"（[release notes](https://support.claude.com/en/articles/12138966-release-notes)）；早期（2025 年中前）Standard 不含、需 Premium——历史口径漂移。

  - Claude Code 各 surface（CLI / VS Code / JetBrains / Desktop / Web）之间是否共享同一池——help center 暗示跨 surface 共享（"all activity in both tools counts against the same usage limits"），但跨设备的合并机制（[code.claude.com costs](https://code.claude.com/docs/en/costs.md) 提"usage from other devices or claude.ai is not included" 指 `/usage` 显示的局限，而非池不合并）需进一步核对。

## 6. 对 Data Provider / Recommendation Policy 的建议（供后续 ticket 引用）

- **最小来源契约**：[claude.com/pricing](https://claude.com/pricing)（订阅档位+对比表）+ [help article 11145838](https://support.claude.com/en/articles/11145838-using-claude-code-with-your-pro-or-max-plan)（Pro/Max Claude Code 用量数值）+ [help article 9266767](https://support.claude.com/en/articles/9266767-what-is-the-team-plan)（Team 周窗口与坐席）+ [help article 9797531](https://support.claude.com/en/articles/9797531-what-is-the-enterprise-plan)（Enterprise 按用量计费）+ [supported-countries](https://www.anthropic.com/supported-countries)（地区清单）五页覆盖全部核心字段，均为静态可抓。
- **核心字段（缺失应阻止强排名）**：价格、计费周期、是否含 Claude Code、5 小时窗口与周窗口相对值（5x / 20x Pro）、上下文长度、地区是否支持、训练用途（Consumer Opt-out vs Commercial 默认不训练）。
- **失败分类建议**：`OK`（定价页/help/公告静态页全文）；`RENDER_DEPENDENT`（[claude.com/pricing](https://claude.com/pricing) 月/年切换、Team/Enterprise 切换）；`LOGIN_REQUIRED`（[claude.ai/upgrade](https://claude.ai/upgrade)、[claude.ai/settings/data-privacy-controls](https://claude.ai/settings/data-privacy-controls)、个人年付币种价格）；`API_AVAILABLE`（Console Usage 页与 Admin API 用于团队/Enterprise 用量与计费）。
- **Claude Code vs API 区分建议**：在 schema 中将 `billing_path` 列为枚举 `subscription_pool` / `api_token`；认证方式（OAuth token vs API key）即该字段的代理变量；当前 Claude Code v2.1.198 起同一 CLI 支持两种认证——`CLAUDE_CODE_OAUTH_TOKEN` 走订阅池，`ANTHROPIC_API_KEY` 走 API 池（[GitHub Actions docs](https://code.claude.com/docs/en/github-actions)）。
- **监控点**：[anthropic.com/news](https://www.anthropic.com/news)（定价与政策类）、[code.claude.com whats-new](https://code.claude.com/docs/en/whats-new/)（Claude Code 周功能）、[release notes](https://support.claude.com/en/articles/12138966-release-notes)（产品总览）、[supported-countries](https://www.anthropic.com/supported-countries)（地区清单——Anthropic 调整地区策略时此处会改）。
- **归一化提醒**：Claude Code 5 小时窗口 + 周窗口 + Opus 池三维桶制与 Cursor 的"双池 + on-demand"、腾讯 CodeBuddy 的"积分"、Gemini Code Assist 的"代码类 6000/天 + chat 960/天 + agent 1500/天"等不可直接换算；建议建模时为每个 Vendor 保留"原始表达 + 归一化表达"双字段，由 schema 层解释映射规则。
